# ontology-components

WarmHub component source repo for the ontology method and grounding/provenance suites.

Install both components in a WarmHub repo:

```bash
wh component install warmhub-data/ontology --repo <org>/<repo>
wh component install warmhub-data/grounding --repo <org>/<repo>
```

## Contents

- `components/ontology/warmhub/` — ontology component
- `components/grounding/warmhub/` — grounding component

Each package contains its component metadata and declarative WarmHub manifest.
